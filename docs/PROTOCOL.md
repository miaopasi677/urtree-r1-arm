# R1-7A 电机通讯协议说明（含本程序实现对照）

> 依据：《Unitree R1-7A 说明文档 · 电机驱动文档》（https://support.unitree.com/home/zh/R1-7a ，访问于 2026-10-12）。
> 该文档声明协议参考「宇树 IM6014 电机协议」。本文档是**本程序实现**的对照说明，改协议层代码前先通读。

## 1. 总线参数

| 项目 | 值 |
| --- | --- |
| 接口 | RS-485 串口 |
| 波特率 | **6.0 Mbps**（8 数据位、无校验、1 停止位） |
| 控制流程 | 周期发送 20 字节指令帧 → 电机返回 26 字节状态帧；**无命令则不返回** |
| 电机 ID | 0~14（本臂 7 颗用 0~6）；15 = 广播（无返回） |
| 字节序 | 多字节变量小端序 |

注意：6 Mbps 属高波特率，USB-RS485 适配器必须支持（宇树有配套模块）；适配器不支持时表现为「完全无应答」。

## 2. 指令帧（20 字节）

| 字节 | 字段 | 说明 |
| --- | --- | --- |
| 0~1 | head | `0xFE 0xEE`（**参与 CRC**） |
| 2 | id/status/timeout | 位域：`bit7=timeout`，`bit6~4=status`，`bit3~0=id` |
| 3 | res | 保留，填 0 |
| 4~5 | tor_des | int16，前馈力矩（转子端），2560 = 1 N·m |
| 6~7 | spd_des | int16，目标速度（转子端），64/2π = 1 rad/s |
| 8~11 | pos_des | int32，目标位置（转子端），32768/2π = 1 rad |
| 12~13 | k_pos | 位置刚度（转子端），12800 = 1 N·m/rad |
| 14~15 | k_spd | 速度刚度（转子端），51200 = 1 N·m·s/rad |
| 16~19 | CRC32 | CRC32-MPEG2，**覆盖前 16 字节（含帧头）** |

- `status`：0 = 停机（上电默认），1 = FOC；
- `timeout`：1 = 开启保护（**超过 1 s 无指令电机自动停机**）。本程序恒为 1（安全默认）；
- 触发超时保护后，状态帧 timeout 标志置 1，**需控制位发 0 清除**。

## 3. 状态帧（26 字节）

| 字节 | 字段 | 说明 |
| --- | --- | --- |
| 0~1 | head | `0xFC 0xEE`（**不参与 CRC**） |
| 2 | id/status/timeout | 同指令帧位域；timeout=1 表示电机触发了超时保护 |
| 3 | temp1 | int8，驱动温度 ℃（-100~127） |
| 4 | temp2 | uint8，绕组温度 ℃（0~255） |
| 5 | vol | uint8，电机端电压，**2 LSB = 1 V**（即电压 = 原始值 ÷ 2） |
| 6~7 | torque | int16，当前转子扭矩，2560 = 1 N·m |
| 8~9 | speed | int16，当前转子速度，64/2π = 1 rad/s |
| 10~13 | pos | int32，当前转子位置，32768/2π = 1 rad |
| 14~17 | MError | uint32 错误码，按位表示，非 0 触发自动停机（含义见官方文档表 1） |
| 18~19 | RES1/MWarning | bit12~0 保留；bit15~13 警告码 |
| 20~21 | RES2 | 保留 |
| 22~25 | CRC32 | CRC32-MPEG2，**覆盖第 2~21 字节（20 字节，不含帧头）** |

## 4. CRC32-MPEG2 实现要点

- 多项式 `0x04C11DB7`，初值 `0xFFFFFFFF`，无终态异或，非反射（MSB first）；
- 官方 C 参考代码按 **32 位字**处理：`ptr` 指向覆盖区首地址，`len` 为字数（指令帧 4、状态帧 5）；小端机器上每个字 = 4 个连续字节按小端拼成，位序自 bit31 到 bit0；
- 本程序 `protocol.crc32_mpeg2()` 与该 C 代码逐位一致；
- **与标准 CRC-32/MPEG-2 的等价关系**：`crc32_mpeg2(data)` == 标准算法作用于「每 4 字节反转后的 data」。标准算法的公认校验值 `CRC-32/MPEG-2("123456789") = 0x0376E6E7`，测试用这一链条交叉验证（tests/test_protocol.py）。

### 回归向量（改动 protocol.py 后必须复现）

用 `tools/gen_protocol_vectors.py` 重新生成并对照：

```
指令帧（motor_id=0, 6010, pos=+0.5 rad 输出端, kp=10, kd=0.5, FOC, timeout=1）:
  FE EE 90 00 00 00 00 00 F3 45 01 00 7D 00 19 00 F8 72 82 F4
状态帧（motor_id=3, 6014, pos=-0.7 rad, tau=2.0 N·m, spd=0.5 rad/s, 48V, 41/55℃）:
  FC EE 13 29 37 60 94 01 41 00 61 4B FF FF 00 00 00 00 00 00 00 00 3B EF 30 58
CRC32-MPEG2('12345678' 按字处理) = 0xFEFC54F9
```

（指令帧核对点：byte2=0x90 → timeout=1/status=1/id=0；pos_raw=0x000145F3=83443=0.5×32×5215.19；k_pos=0x7D=125=10/32²×12800；k_spd=0x19=25=0.5/32²×51200。）

## 5. 单位换算（转子端 ↔ 输出端）

本程序对外的所有物理量都是**输出端**（关节侧），组帧/解析时自动换算：

| 物理量 | 转子端原始值 → 物理量 | 输出端 → 转子端原始值 |
| --- | --- | --- |
| 位置 pos | `rad_out = raw / (ratio × 32768/2π)` | `raw = rad_out × ratio × 32768/2π` |
| 速度 spd | `rad/s_out = raw / (ratio × 64/2π)` | `raw = rad/s_out × ratio × 64/2π` |
| 力矩 tor | `N·m_out = raw / 2560 × ratio` | `raw = N·m_out / ratio × 2560` |
| 刚度 kp | `N·m/rad_out = raw / 12800 × ratio²` | `raw = kp_out / ratio² × 12800` |
| 阻尼 kd | `N·m·s/rad_out = raw / 51200 × ratio²` | `raw = kd_out / ratio² × 51200` |

减速比（R1-7A 文档第三章）：`6010 = 32`，`6014 = 12.666`，`5010 = 16`。

数值上限（原始值）：tor/spd 为 int16（±32767 → 力矩约 ±12.8 N·m 转子端）；pos 为 int32；k_pos/k_spd 程序按 [0, 32767] 保守钳位。超范围数值在 `build_command_frame` 内自动钳位。

## 6. 关节-电机映射与行程（arm_config.json 默认值）

| 关节 | 电机 ID | 型号/减速比 | 行程（开发文档） | 备注 |
| --- | --- | --- | --- | --- |
| J1 底座回转 | 0 | 6010 / 32 | -156° ~ +156° | 展示左右旋 |
| J2 大臂 | 1 | 6010 / 32 | 0° ~ 180° | |
| J3 | 2 | 6014 / 12.666 | -20° ~ +200° | |
| J4 小臂 | 3 | 6014 / 12.666 | -180° ~ 0° | ⚠ 官网产品页写 0°~180°，首次点动确认方向 |
| J5 腕 | 4 | 6014 / 12.666 | -130° ~ +130° | |
| J6 腕 | 5 | 5010 / 16 | -30° ~ +30° | |
| J7 末端法兰 | 6 | 5010 / 16 | -90° ~ +90° | 末端旋转用 |

零位约定：`joint_deg = direction × (motor_output_deg − offset_deg)`。`offset_deg` 由现场 `teach` 的 `zero` 命令标定写入；`direction`（±1）用于方向不一致时翻转。

## 7. 通信时序要求

- 控制环默认 **200 Hz**（`control.rate_hz`）：每周期把 7 帧指令一次性写入，再在 `read_timeout_ms`（默认 3 ms）窗口内收齐状态帧；
- 因为开启了电机侧 1 s 超时保护，**任何进程退出/崩溃都会让电机在 1 s 内自动停机**——这是安全设计，不要为「保持姿态」关闭它；
- 多电机共享一条总线：本程序采用「突发写 + 窗口收」的轮询制；若实测收帧率不足（`monitor` 看环路 Hz 明显低于设定值），优先检查适配器/驱动，其次把 `read_timeout_ms` 提高到 4~5 ms。

## 8. 修改协议层的检查单

1. 通读官方 R1-7A 文档对应章节（字段/CRC/换算是否有修订）；
2. 只改 `src/r1arm/protocol.py`（帧格式、换算、CRC），不要把业务逻辑混进去——总线/控制层依赖它的纯函数语义；
3. 跑 `python tests/run_tests.py`（CRC 交叉验证、帧往返、换算往返会拦截大部分笔误）；
4. 跑 `python tools/gen_protocol_vectors.py`，与本文档第 4 节向量对照；向量变化时要更新文档；
5. `python r1ctl.py --sim check` + `--sim demo --cycles 1` 仿真回归；
6. 真机 `python r1ctl.py check`，确认电机应答后再继续。
